# Earthquake Forecasting Dashboard

## Project Overview
Earthquake time-series analysis and forecasting.

## Models
- ARIMA
- SARIMA
- RNN
- LSTM
- Prophet

## Features
- Exploratory Data Analysis
- Stationarity Testing
- ACF and PACF
- Time Series Decomposition
- Forecasting
- Model Evaluation
- Streamlit Dashboard

## Installation
pip install -r requirements.txt

## Run Dashboard
streamlit run app.py

## Technologies
Python, Pandas, NumPy, Matplotlib, Statsmodels,
Scikit-learn, TensorFlow, Prophet, Streamlit
